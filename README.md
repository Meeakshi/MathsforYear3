# Year 3 Maths Quest

A practice site covering every topic in the Year 3 maths programme of study (National Curriculum for England): place value, adding and subtracting, times tables, fractions, measurement, money and time, shapes and angles, and charts.

- 46 topics, with fresh questions generated every round
- 10 questions per round, with worked explanations for wrong answers
- Stars for each topic, saved in the browser

Open `index.html` in any browser. No install or build step needed.
