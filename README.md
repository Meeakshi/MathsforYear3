# Primary Maths Quest

A practice site for every primary year (Years 1–6) of the maths programme of study in the National Curriculum for England.

- Children pick their school year (with age shown) and get that year's topics: 220 topics in total
- Fresh questions every round, 10 per round, with worked explanations for wrong answers
- Stars for each topic, saved in the browser
- Add `#year-4` (etc.) to the link to open a year directly

Open `index.html` in any browser. No install or build step needed.

## Files
- `index.html`: the site
- `js/core.js`: shared helpers, drawings and question makers
- `js/y1.js` … `js/y6.js`: each year's topics
- `js/app.js`: year picker, quiz and progress
- `year3-maths-quest.html`: the same page in the format used for the claude.ai version
